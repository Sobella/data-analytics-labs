# R Statistics Lab

A small R project I made for a data analytics class while learning the basics of statistics and working with data.

**Date:** December 2022

## About

This lab focuses on using R to work with data and perform some basic statistical analysis. It includes creating random samples, calculating statistics, making histograms, working with functions, and reading data from the U.S. Census.

## What It Does

* Creates a random sample using a normal distribution
* Calculates the mean and standard deviation
* Creates histograms
* Calculates skewness
* Creates a custom function to calculate the mean
* Reads population data from the U.S. Census
* Cleans and converts data for analysis

## What I Learned

This project gave me practice with:

* R programming
* Basic statistics
* Functions
* Vectors and lists
* Data frames
* Data cleaning
* Reading data from an external source
* Basic data visualization
