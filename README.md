# Data Analytics Labs

A collection of data analytics labs and projects I worked on while learning different data analysis and statistics concepts.

Most of these are from my coursework and were originally completed in 2022.

## Projects

### R Statistics Lab

An introduction to statistics and working with data in R.

Topics covered:

* Normal distributions
* Mean and standard deviation
* Histograms
* Skewness
* R functions
* U.S. Census data

### Lab 1 - Sampling and Regression

An R lab focused on sampling, probability, z-scores, correlation, and linear regression.

Topics covered:

* Random sampling
* Sampling distributions
* Z-scores
* Normal distributions
* Correlation
* R-squared
* Linear regression
* Regression analysis

## Tools

* R

* Data analysis
